# obs sync 接入与本机部署

当前部署使用 fast-note-sync-service 的用户 1、Vault 1，映射到 nav 用户 1。源数据库和同步文件只读访问。

`scripts/obs-sync-export.py` 将源记录中的路径恢复为标准 Vault，包含 Markdown 与附件。默认输出 `/root/nav-obs-sync/vault`；可通过 `NAV_OBS_EXPORT_DIR` 修改输出基目录，通过 `OBS_SYNC_STORAGE` 修改源 storage 目录。需要 Python 3.11+。

本机 root crontab 每分钟运行 `/root/nav-obs-sync/export.py`，该入口调用仓库内脚本。日志为 `/root/nav-obs-sync/last-run.log`。导出先暂存源文件，再替换有变化的文件；不会一次性把所有附件读入内存。删除仅针对上次导出的文件，源文件缺失会中止本轮导出。

`.env` 启用 Obsidian、设置单用户 ID 为 1、将导出目录只读挂载到 `/vaults`，索引刷新间隔为 60 秒。笔记上限设为 8 MiB，以容纳现有的大笔记。索引在访问知识库时按间隔刷新，不是独立后台定时器。
