# 桌宠伙伴栏重构（2026-09-09）

首页入口改为紧凑伙伴栏。点击角色、名字或箭头打开互动卡片，移动由独立把手负责，移除双击、长按和巡逻作为首页入口的依赖。

## 行为

- 卡片提供打招呼、休息/唤醒、安静陪伴、最多四个常用工具、设置与收起。
- 收起后保留星星恢复按钮。Escape 关闭卡片并恢复焦点，移动把手支持方向键。
- 拖动、改变屏幕尺寸、恢复保存位置都使用同一套边界计算。手机保留安全边距。
- 打开知识库、AI、音乐或日历时自动避让；不会在关闭工具时意外展开原先已收起的伙伴。
- 休息、收起、页面隐藏、工具遮挡和减少动态设置均暂停角色动画。真实任务状态独立更新。
- 销毁时清理角色、状态订阅、事件监听、观察器和计时器，重新启用只建立一个实例。

## 设置

设置页使用真实角色预览、首页显示偏好和工具选择。站岗/巡逻只控制本页动作演示，不影响首页伙伴栏位置。保留已有名字、自定义形象、尺寸和位置偏好。

同账号页面之间广播设置；接收方只更新内存缓存，不额外触发整份数据的 PUT。不同账号使用独立频道。
