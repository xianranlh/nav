# 统一视觉与桌宠交互

`styles/theme-tokens.css` 提供首页、登录页和宠物页共用的基础主题变量；`styles/unified.css` 提供表面、文字、边框与操作色。其后加载的 AI 布局只引用共享颜色，玄鸟和液态玻璃保留各自材质覆盖。六种风格保留各自的背景、文字、表面与粒子；品牌主色可自定义，重置跟随当前风格。切换时仅自动替换上一风格的默认主色，已有自定义颜色（包括蓝灰色）保留。背景图片仍可自定义，错误、完成等语义状态保留区别。

分组标题和标签使用 `js/astral-icons.js` 的 `star-badge` 线性五角星，继承统一主色，装饰性 SVG 不重复朗读标题。原猫头素材不再引用。

## 桌宠

- 首页点击角色打招呼，点击可见的「⋯」打开快捷动作与行为设置；右键、长按和键盘菜单键也能打开。
- 操作面板可用 Escape 关闭并恢复焦点；收起后留下星星恢复按钮。
- 站岗支持拖动和方向键移动，保存相对位置；拖动不触发招呼，窄屏与减少动态模式自动站岗。
- 打开知识库等模态框或 AI、音乐、日历面板时自动避让并暂停；关闭后恢复。
- 关闭首页桌宠时销毁角色、订阅、观察器、计时器和局部事件，再开启时只创建一个实例。
- 设置页跟随首页视觉主题、主色及明暗偏好；预览角色随场地尺寸调整位置。动作预览仅作用于当前角色，不发布虚假的离线或工作状态。
- 桌宠动画在隐藏页面、收起、面板交互、减少动态时暂停；静态设置页移除背景粒子。
